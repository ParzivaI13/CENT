# CENT App - 3D Cargo Loadout Optimizer

A web application built with Angular 21 and Three.js for interactive 3D/2D visualization of trailer loading and cargo optimization.

## Key Features
- **3D & 2D Visualization**: Real-time rendering of trailers and cargo using Three.js.
- **Cargo Management**: Create, edit, and spawn custom pallets with configurable dimensions, color, and stackability.
- **Trailer Configuration**: Customize trailer dimensions and save trailer profiles.
- **Auto-Loadout Algorithm**: Automatically calculate and optimally place cargo inside the selected trailer.
- **Interactive Editor**: Rotate, maneuver, and delete loaded cargo in real time.
- **Internationalization (i18n)**: Support for English and Ukrainian languages.
- **Themes**: Light and dark mode support.
- **Firebase Integration**: Authentication and cloud data storage.

## Tech Stack
- Angular 21
- Three.js
- Firebase

# CENT App - 3D Оптимізатор Завантаження

Веб-застосунок, створений на базі Angular 21 та Three.js, для інтерактивної 3D/2D візуалізації завантаження трейлерів та оптимізації розміщення вантажу.

## Основний Функціонал
- **3D та 2D Візуалізація**: Рендеринг трейлерів та вантажу в реальному часі за допомогою Three.js.
- **Керування Вантажем**: Створення, редагування та розміщення власних палет із налаштуванням розмірів, кольору та можливості штабелювання (stackable).
- **Налаштування Трейлера**: Зміна розмірів трейлера та збереження власних профілів.
- **Алгоритм Автозавантаження**: Автоматичний розрахунок та оптимальне розміщення вантажу всередині обраного трейлера.
- **Інтерактивний Редактор**: Обертання та видалення вантажу в режимі реального часу.
- **Локалізація (i18n)**: Підтримка англійської та української мов.
- **Теми**: Підтримка світлої та темної тем оформлення.
- **Інтеграція Firebase**: Аутентифікація та хмарне збереження даних.

## Технологічний Стек
- Angular 21
- Three.js
- Firebase
